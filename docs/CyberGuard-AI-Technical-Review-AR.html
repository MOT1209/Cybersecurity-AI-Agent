02 · Architecture

المعمارية الحالية

واجهة SPA (React 19 + Vite) تتحدث إلى خادم Express واحد عبر src/lib/api.ts الذي يحقن ترويسة x-api-key. الطبقة الخلفية الجديدة نُظّمت في 21 ملف TypeScript تحت src/server/ موزّعة على ست وحدات:

الوحدةالمسؤوليةالحالة
llm/طبقة مزودين (Claude · Gemini · Local) + wrapUserInput لحماية الحقن + تدرّج تلقائيREAL
core/مخازن الحالة، تحقّق المدخلات، بوابة الأمان، ومحرّك التعافي من الأخطاءREAL
sandbox/واجهة تنفيذ قابلة للتبديل: DockerExecutor معزول + LocalSimExecutor احتياطيREAL
tools/محوّل nmap (تحقّق Zod + تحليل المنافذ) — نمط تُبنى عليه بقية الأدواتPARTIAL
agents/BaseAgent + وكيل Recon الحقيقي (ذاكرة سياق، سجل أدوات، تدرّج)PARTIAL
orchestrator/runMission: يشغّل Recon فعلياً ثم يركّب البقية عبر LLM + قالب احتياطيPARTIAL

مسار الطلب أثناء مهمة

SPA→ Express API→ Security Gateway→ Recon Agent→ Sandbox (nmap)→ LLM Synthesis→ Plan + Findings

العُقد الخضراء تنفيذ حقيقي؛ خطوة التركيب تستخدم النموذج الحيّ إن توفّر، وإلا تتدرّج إلى قالب حتمي.

05 · Security Posture

الوضع الأمني

البنية الأمنية جادّة ومغطّاة باختبارات، لكن فيها فجوات معروفة يجب ألا تُنسى قبل أي استخدام خارج المختبر.

ضوابط قائمة وفعّالة

Sandbox isolation
حاوية بـ CapDrop: ALL، جذر للقراءة فقط، no-new-privileges، حدّ 1 CPU / 512MB، ومهلة قسرية 60 ثانية.
Prompt injection
كل إدخال غير موثوق يُغلَّف بـ wrapUserInput ويُعامَل كبيانات لا تعليمات، مركزياً في طبقة المزودين.
Auth & rate limits
مصادقة x-api-key على كل /api، وحدّان: 60/15د عام و15/15د للذكاء.
Audit trail
كل تنفيذ يُسجَّل مع outputHash (sha256) للمخرجات — أساس تتبّع النتائج في التقارير.

فجوات أمنية مفتوحة

⛌ بوابة قابلة للتجاوز

validateSecurityGateway تعتمد String.includes للنطاق؛ يمكن خداعها بسلاسل فرعية (مثل نطاق يحتوي كلمة مسموحة). تحتاج تحليل مضيف/شبكة صارماً.

⚠ موافقة بشرية بلا إنفاذ

الأدوات عالية الخطورة تُعلَّم بـ humanApprovalRequired لكن لا يوجد إنفاذ فعلي يوقف التنفيذ بانتظار الموافقة.

⚠ لا تخزين دائم

سجلّات التدقيق والنتائج في الذاكرة فقط؛ تُفقد عند إعادة التشغيل، ما يضعف قابلية التدقيق طويل الأمد.

⛌ مفاتيح محروقة سابقاً

تاريخياً تسرّبت مفاتيح API في مواضع أخرى للمستخدم؛ يجب تأكيد تدوير كل المفاتيح وعدم إيداع أي سرّ في الكود.
