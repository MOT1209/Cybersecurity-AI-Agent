Strategic Roadmap · v1

من عرض توضيحي إلى منصة تعلّم واختراق agentic حقيقية

خارطة طريق كاملة لتطوير CyberAgent AI: تنفيذ حقيقي للأدوات في حاويات معزولة، حلقة وكلاء بحقيقة استدعاء الأدوات، ونواة تعليمية تمشي معك خطوة بخطوة — لتعلّم الأمن السيبراني والاختراق الأخلاقي.

التنفيذ: Sandbox حقيقي الهدف: تعلّم + pentest المحرك: متعدد المزودين المنفذ: 7799
Baseline

أين نحن الآن — وإلى أين نتجه

المشروع اليوم واجهة أنيقة فوق منطق محاكاة. الفجوة الحقيقية ليست في الشكل بل في العمق: لا تنفيذ فعلي، ولا ذاكرة، ولا حلقة وكلاء حقيقية. هذه الخطة تسدّها.

الوضع الحالي

  • الوكلاء الـ12 = ميتاداتا + ردود fallback ثابتة
  • الأدوات محاكاة — لا nmap/nuclei فعلي
  • الأوركستريتور يعيد خطة مكتوبة سلفاً
  • كل الحالة في الذاكرة — تُفقد عند إعادة التشغيل
  • مزوّد AI واحد (Gemini) بلا استدعاء أدوات

المستهدف

  • وكلاء حقيقيون يستدعون أدوات ويقرؤون مخرجاتها
  • تنفيذ فعلي في حاويات Docker معزولة
  • حلقة Plan→Act→Observe→Reflect ديناميكية
  • تخزين دائم (SQLite) + تتبّع تقدّم تعليمي
  • طبقة Claude + Gemini + محلي قابلة للتبديل

Roadmap

مراحل التنفيذ

سبع مراحل متتابعة، كل واحدة قابلة للشحن والاختبار وحدها. المرحلة صفر أُنجزت فعلاً في جلسة الإصلاحات.

PHASE 0DONE ✓

أساس نظيف

إصلاح المصادقة (apiFetch/x-api-key)، ضبط النموذج، تعقيم /api/health، vitest + CI، المنفذ 7799.

PHASE 1NEXT

الأساس المعماري

تخزين دائم، طبقة تجريد AI متعددة المزودين، تفكيك server.ts.

  • SQLite + Prisma بدل المخازن في الذاكرة
  • واجهة LLMProvider موحّدة (Claude/Gemini/محلي)
  • src/server/{routes,agents,tools,llm,db}
PHASE 2PLANNED

حلقة الوكلاء الحقيقية

محرك tool-calling حقيقي + سجل أدوات + بث مباشر (SSE) + ذاكرة وكيل.

PHASE 3PLANNED

تنفيذ Sandbox (Docker)

مشغّل حاويات معزول (dockerode)، تقوية البوابة بمطابقة CIDR، مختبر محلي جاهز، أول موجة أدوات حقيقية.

PHASE 4PLANNED

نواة التعلّم

مسارات تعلّم، مولّد CTF بتتبّع تقدّم، وضع «المرشد» يشرح كل خطوة، مختبرات موجّهة.

PHASE 5PLANNED

تعميق التغطية

أدوات DAST/Cloud/Container/Forensics إضافية، مكاملات استخبارات، مولّد تقارير احترافي.

PHASE 6PLANNED

الصقل والإنتاج

مصادقة مستخدمين وRBAC، تفكيك المكوّنات الضخمة، اختبارات E2E، Dockerfile للإنتاج.

New Ideas

أفكار جديدة نضيفها

ما يميّز المنصة عن مجرد «واجهة لأدوات» — تعلّم من الهجوم والدفاع معاً.

01

Attack ↔ Defense مزدوج

لكل هجوم يكتشفه الوكيل، وكيل مدافع يقترح قاعدة كشف (Sigma / YARA / WAF) — تتعلّم الجانبين معاً.

02

Purple Team Simulator

محاكاة سلسلة هجوم MITRE ATT&CK كاملة على المختبر مع خط زمني للأحداث.

03

مختبر توليدي فوري

«اشرح هذه الثغرة كأني مبتدئ» → الوكيل يولّد بيئة ضعيفة مصغّرة لتجربتها حيّاً.

04

تقارير مدعومة بالأدلة

كل بند في التقرير مربوط بمخرَج أداة حقيقي (traceability كامل).

05

مسار شهادات محاكٍ

تتبّع تقدّم نحو أهداف تشبه OSCP / eJPT بشكل تعليمي.

06

مكتبة Payloads تفاعلية

حمولات آمنة مشروحة مع تأثير كل واحدة وكيفية التحصين ضدها.

07

وضع «الخصم» للتدريب

الوكيل يهاجم كودك أو إعدادك ثم يعلّمك كيف تحصّنه.

08

تكامل Git

يفحص ريبو حقيقياً (SAST + secrets) ويشرح النتائج تعليمياً سطراً بسطر.

Guardrails

مصفوفة الأمان الحاكمة

هذه أداة دفاعية/تعليمية. قواعد صارمة تُطبَّق في كل مرحلة قبل أي تنفيذ حقيقي.

SCOPE

أهداف المختبر المحلي فقط. كل تنفيذ يمرّ عبر Security Gateway بمطابقة CIDR فعلية؛ أي هدف إنترنت يُرفض تلقائياً.

ISOLATE

عزل شبكي كامل. الأدوات تعمل في حاويات بشبكة bridge خاصة أو --network none، بحدود CPU/ذاكرة ومهلة تنفيذ.

APPROVE

منع صريح للأدوات عالية الخطورة. zap/bruteforce/exploit تتطلب موافقة صريحة — لا مجرد وسم كما في الكود الحالي.

AUDIT

سجل تدقيق دائم. كل استدعاء أداة ونتيجة يُسجَّل في SQLite بمعرّف تتبّع (traceId) قابل للمراجعة.

INPUT

دفاع حقن الأوامر. يُحتفظ بتغليف <user_input> وحدود الطول، وتُعامَل مدخلات المستخدم كبيانات لا كتعليمات.
